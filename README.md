
# AI-Based Smart Allocation for PM Internship Scheme

## About the Project
This project is a web-based portal that recommends suitable internships to candidates based on their skills and interests.

## Features
- Candidate Registration
- Store candidate details using SQLite
- View Registered Candidates
- Recommend suitable internships

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS

## How to Run
1. Install Python.
2. Install Flask:
   `pip install flask`
3. Run the application:
   `python app.py`
4. Open `http://127.0.0.1:5000` in your browser.
